# ADR-0002: глобальный хэндл UART через UnsafeCell + unsafe impl Sync

> [!abstract] Суть
> Для `print!`/`panic_handler` хэндл UART живёт в статической памяти: обёртка с `UnsafeCell<Pl011>` + ручной `unsafe impl Sync`. Инвариант «одно ядро, IRQ замаскированы» ([[multicore_path]]) — честно написан как комментарий-обещание; на этапе 4 заменяется настоящим SpinLock с сохранением API.

## Контекст
`print!` и `panic_handler` должны работать из любого места, а не только из кадра `main`. `static` в Rust требует `Sync` и неизменяемости → нужна интерьерная мутабельность. Альтернативы: `static mut` — запрещён в edition 2024 (`static_mut_refs`), UB-минный; `spin::Mutex` — новая зависимость и спрятанная механика, конфликтует с планом этапа 4 (свой SpinLock).

## Решение
- `struct`-обёртка над `UnsafeCell<Pl011>`, `unsafe impl Sync` с комментарием-инвариантом;
- `static UART` инициализируется компиляцией — возможен благодаря `pub const fn new` ([ADR-0001]);
- известное ограничение: паника *внутри* печати создаёт алиасинг `&mut` (второй из обработчика) — на одном ядре не стреляет, на этапе 4 закрывается `try_lock`'ом в панике;
- все печати — через глобальный хэндл, локальный экземпляр в `main` удаляется.

## Последствия
- + видна точка обещания (`unsafe impl Sync`) — учебная ценность;
- + без новых зависимостей; API готов к SpinLock (этап 4);
- − ручной `unsafe` с инвариантом на совести разработчика до этапа 4;
- − алиасинг при панике из печати — отложено на этап 4.
