# ADR-0003: порядок этапа 3 — исключения до GIC

> [!abstract] Суть
> Этап 3 (прерывания) начинается не с GIC, а с exception-фундамента: VBAR_EL1 + таблица векторов + печатающий обработчик. GICv3 и таймер подключаются вторым шагом. Причина: без векторов любая ошибка этапа = тихое зависание; с ними — печатаемое падение.

## Контекст
Этап 2 закрыт (MMU identity map, heap). Плата недоступна — работа в QEMU ([[qemu_adaptation]]). Отвергнутая альтернатива: сначала [[board_abstraction]] — трейт-граница ложится на готовый драйвер в любой момент, а печатающие векторы упрощают ВСЕ следующие этапы.

## Решение
1. Теория исключений AArch64 (классы, векторы, VBAR_EL1) — заметка.
2. Задание: таблица векторов + печать класса/адреса исключения + тест «провокация fault».
3. GICv3: GICD/GICR, включение, приоритеты.
4. ARM-таймер: первый тик IRQ.

## Последствия
- + все падения печатаются с этого момента — качество отладки качественно растёт;
- + таймер становится базой для планировщика (этап 5);
- − этап сдвинут на шаг от «просто GIC» из README.
