# Дескрипторы страниц AArch64

> [!abstract] Суть
> Запись таблицы страниц — 64 бита: тип (Table/Block/Page), выходной адрес (выровнен на размер блока) и атрибуты. Критический бит — AF (Access Flag): без него любое обращение даёт Access fault, который до VBAR_EL1 выглядит тихим зависанием.
> Два сорта по смыслу: **Table** = «смотри дальше» (значение — PA следующей таблицы | 0b11); **Block/Page** = «правило трансляции» (значение — PA региона | атрибуты). Типичная ошибка в Rust — ORить ссылку-переменную на таблицу вместо её адреса: нужен `&raw const TABLE as usize`.

## Типы дескрипторов

| Тип | Биты [1:0] | Где живёт | Output Address |
|---|---|---|---|
| Table (→ следующая таблица) | 0b11 | L0, L1, L2 | PA таблицы, биты [47:12] |
| Block 1 ГБ | 0b01 | L1 | OA[47:30] в битах [47:30] |
| Block 2 МБ | 0b01 | L2 | OA[47:21] в битах [47:21] |
| Page 4 КБ | 0b11 | L3 | OA[47:12] в битах [47:12] |

Размер блока определяет, сколько младших битов OA — «смещение» и потому не хранится: 1 ГБ → OA[47:30], 2 МБ → OA[47:21], 4 КБ → OA[47:12].

## Атрибуты Block/Page

| Биты | Поле | Значения |
|---|---|---|
| [4:2] | AttrIndx | индекс кодировки в MAIR_EL1: 0 = Normal, 1 = Device |
| [7:6] | AP | 00 = rw только EL1, 01 = rw все |
| 10 | **AF** | 1 = разрешён доступ; 0 = Access fault |
| 53/54 | PXN/UXN | запрет исполнения (для Device ставят PXN=1) |

## Регистры включения (для 4b)

| Регистр | Что пишем | Комментарий |
|---|---|---|
| MAIR_EL1 | Attr0=0xFF (Normal WB), Attr1=0x04 (Device-nGnRE) → итог **0x04FF** | AttrIndx в дескрипторе = номер байта в MAIR: Attr0 — биты [7:0], Attr1 — [15:8] |
| TCR_EL1 | T0SZ=16 (48 бит VA), TG0=00 (4КБ), IPS=000 (PA до 4ГБ), SH0=11, IRGN/ORGN=01 | VA[47:39..12] — полный 4-уровневый путь |
| TTBR0_EL1 | PA L0-таблицы | наша статика, identity |
| SCTLR_EL1 | бит M=1 (включение MMU); C/I пока 0 | включать последним, после dsb/isb |

> [!warning] Подводные камни
> - **AF=0 → Access fault** при первом обращении к странице; без векторов — тихий hang.
> - L2-индекс для UART: `(0x09000000 >> 21) & 0x1FF = 0x48`; L1-индекс RAM: `0x40000000 >> 30 = 1`.
> - Дескриптор Table vs Block различается битом 1: 0b11 — Table, 0b01 — Block. Перепутать легко.
> - Запись регистров — через `asm!("msr ...")`; после настройки — `dsb sy` + `isb` до SCTLR.M=1.

## Ожидаемые значения (identity map проекта)

- `L0[0] = PA(L1) | 0b11`
- `L1[0] = PA(L2) | 0b11`
- `L1[1] = 0x40000401` — RAM 1 ГБ, Normal (AttrIndx=0), AP=00, AF=1
- `L2[0x48] = 0x09000405` — UART 2 МБ, Device (AttrIndx=1), AP=00, AF=1
